# Implementation patterns

Reusable patterns confirmed in the source app, shown with neutral names. Business logic from the source app is not included.

## 1. Configuration

All deployment values come from the environment. One zod schema parses them once, in the host entry.

```ts
// server/config.ts
import { z } from "zod";

const envSchema = z.object({
  PUBLIC_BASE_URL: z.url(),
  ADMIN_EMAILS: z.string().min(1, "ADMIN_EMAILS must list at least one admin email"),
  BETTER_AUTH_SECRET: z.string().min(32, "BETTER_AUTH_SECRET must be at least 32 characters"),
  GOOGLE_CLIENT_ID: z.string().min(1),
  GOOGLE_CLIENT_SECRET: z.string().min(1),
  CLIENT_IP_HEADER: z.string().optional(),
  ANTHROPIC_API_KEY: z.string().optional(),
  ANTHROPIC_MODEL: z.string().optional(),
  ANTHROPIC_BASE_URL: z.url().optional(),
});

export interface AppConfig {
  baseUrl: string;                 // no trailing slash
  adminEmails: string[];           // lower-cased
  authSecret: string;
  google: { clientId: string; clientSecret: string };
  host: "cloudflare" | "node";
  clientIpHeaders: string[];
  anthropic: { apiKey: string; model: string | null; baseUrl: string | null } | null; // null = AI off
}

export function loadConfig(env: Record<string, unknown>, host: AppConfig["host"]): AppConfig {
  const parsed = envSchema.safeParse(env);
  if (!parsed.success) {
    const problems = parsed.error.issues.map((i) => `${i.path.join(".")}: ${i.message}`);
    throw new Error(`Invalid configuration:\n  ${problems.join("\n  ")}`);
  }
  const v = parsed.data;
  return {
    baseUrl: v.PUBLIC_BASE_URL.replace(/\/+$/, ""),
    adminEmails: v.ADMIN_EMAILS.split(",").map((e) => e.trim().toLowerCase()).filter(Boolean),
    authSecret: v.BETTER_AUTH_SECRET,
    google: { clientId: v.GOOGLE_CLIENT_ID, clientSecret: v.GOOGLE_CLIENT_SECRET },
    host,
    clientIpHeaders: [v.CLIENT_IP_HEADER ?? (host === "cloudflare" ? "cf-connecting-ip" : "x-forwarded-for")],
    anthropic: v.ANTHROPIC_API_KEY?.trim()
      ? { apiKey: v.ANTHROPIC_API_KEY.trim(), model: v.ANTHROPIC_MODEL?.trim() || null, baseUrl: v.ANTHROPIC_BASE_URL ?? null }
      : null,
  };
}
```

Optional features are `null` in config when their key is missing, and the app still runs.

## 2. Host entry and services

```ts
// hosting/cloudflare/worker.ts
import { createRequestHandler } from "react-router";
import { drizzle } from "drizzle-orm/d1";
import { createRouterContext } from "../../app/context";
import { createServices, handleRequest, type Services } from "../../server/app";
import { fetchClientMetadataViaFetch } from "../../server/auth/cimd-fetch";
import { loadConfig, type AppConfig } from "../../server/config";
import * as schema from "../../server/db/schema";

const renderPage = createRequestHandler(() => import("virtual:react-router/server-build"), import.meta.env.MODE);

const configByEnv = new WeakMap<Env, AppConfig>();   // only plain config is cached
function getConfig(env: Env) {
  let config = configByEnv.get(env);
  if (!config) { config = loadConfig(env as unknown as Record<string, unknown>, "cloudflare"); configByEnv.set(env, config); }
  return config;
}

// Built per request on purpose: do not cache Services or the Better Auth instance on Workers.
function buildServices(env: Env): Services {
  return createServices({ config: getConfig(env), db: drizzle(env.DB, { schema }), media: null, fetchClientMetadata: fetchClientMetadataViaFetch });
}

export default {
  async fetch(request, env) {
    return handleRequest(request, buildServices(env), (req, svc) => renderPage(req, createRouterContext(svc)));
  },
} satisfies ExportedHandler<Env>;
```

`Env` is generated by `wrangler types` into `hosting/cloudflare/worker-configuration.d.ts` (part of `npm run typegen`).

## 3. Core services (business rules)

```ts
// server/core/items.ts — no framework, driver, or SDK imports
import { z } from "zod";

export const itemSchema = z.object({
  title: z.string().trim().min(1, "Add a title.").max(200),
  notes: z.string().trim().max(10_000).nullable().default(null),
});
export type ItemInput = z.infer<typeof itemSchema>;
export type FieldErrors = Partial<Record<keyof ItemInput | "form", string>>;

export function validateItem(raw: unknown): { ok: true; value: ItemInput } | { ok: false; errors: FieldErrors } {
  const parsed = itemSchema.safeParse(raw);
  if (parsed.success) return { ok: true, value: parsed.data };
  const errors: FieldErrors = {};
  for (const issue of parsed.error.issues) errors[(issue.path[0] as keyof ItemInput | undefined) ?? "form"] ??= issue.message;
  return { ok: false, errors };
}

export interface Actor { userId: string }

export function createItems({ repo, now, newId }: { repo: ItemsRepository; now: () => Date; newId: () => string }) {
  return {
    get: (id: string) => repo.get(id),
    async create(input: ItemInput, actor: Actor) {
      const at = now();
      const item = { id: newId(), ...input, revision: 1, createdAt: at, updatedAt: at, createdBy: actor.userId, updatedBy: actor.userId, deletedAt: null };
      await repo.insert(item);
      return item;
    },
  };
}
export type Items = ReturnType<typeof createItems>;
```

Results that can fail return discriminated unions (`{ ok: true, value }` / `{ ok: false, reason, message }`), not exceptions.

```tsx
// app/routes/item.tsx
import { data, Form } from "react-router";
import type { Route } from "./+types/item";   // generated by `react-router typegen`

export async function loader({ request, params, context }: Route.LoaderArgs) {
  const services = context.get(servicesContext);
  const item = await services.items.get(params.id);
  if (!item) throw new Response("Not found", { status: 404 });
  return { item, viewer: await getViewer(request, services) };
}

export async function action({ request, params, context }: Route.ActionArgs) {
  const services = context.get(servicesContext);
  const admin = await requireAdminWrite(request, services);   // first line of every write
  const form = await request.formData();
  const valid = validateItem({ title: form.get("title"), notes: form.get("notes") || null });
  if (!valid.ok) return data({ errors: valid.errors }, { status: 422 });
  await services.items.update(params.id, valid.value, { userId: admin.userId });
  return { saved: true };
}

export default function ItemPage({ loaderData, actionData }: Route.ComponentProps) {
  return (
    <Form method="post">
      <input name="title" defaultValue={loaderData.item.title} />
      {actionData && "errors" in actionData && actionData.errors.title && <p role="alert">{actionData.errors.title}</p>}
      <button>Save</button>
    </Form>
  );
}
```

Admin gates (confirmed):

```ts
// app/admin.server.ts
export async function requireAdminPage(request: Request, services: Services) {   // GET pages
  const viewer = await getViewer(request, services);
  if (viewer?.isAdmin) return viewer;
  if (viewer) throw new Response("Only admins can do that.", { status: 403 });
  const url = new URL(request.url);
  throw redirect(`/sign-in?next=${encodeURIComponent(url.pathname + url.search)}`);
}
export async function requireAdminWrite(request: Request, services: Services) {  // actions
  const viewer = await getViewer(request, services);
  if (viewer?.isAdmin) return viewer;
  throw new Response(viewer ? "Only admins can do that." : "Sign in as an admin to do that.", { status: viewer ? 403 : 401 });
}
// app/session.server.ts: getViewer() = auth.api.getSession({ headers }) + isAdmin from the allow-list, every request.
```

Root loader returns `viewer` for the whole UI; components read it with `useRouteLoaderData("root")`.

## 5. Errors

| Where | Pattern |
| --- | --- |
| Loaders/actions | `throw new Response(message, { status })` for 401/403/404; `return data({ errors }, { status: 422 })` for form validation |
| UI | Root `ErrorBoundary` uses `isRouteErrorResponse(error)`; shows the thrown string for 401/403/other statuses, a "Not found" page for 404, and a generic message otherwise |
| JSON routes | `Response.json({ message }, { status })`. Messages are plain language and safe to show |
| AI | Adapter returns `AiResult` failures; never leaks SDK error text to users |
| MCP | Business errors as tool results with `isError: true` and `{ status, message }`; auth errors as HTTP 401 |
| HTTP API | `{ status, message }` with matching HTTP status; `Cache-Control: no-store` |
| Config | `loadConfig` throws one readable error listing every bad variable |

## 6. Logging and health

- Logging is minimal: `console.error` for AI failures and post-shell render errors. No logging library. Workers `observability.enabled: true` collects logs; `npx wrangler tail <WORKER_NAME> --format json` streams them.
- Never log secrets, tokens, or request bodies.
- `/health` returns `{ ok, host, checks }` and runs `select count(*) from user` and the media `ping()`; status 503 when a check fails.

## 7. Input bounds and safety

- Bound every input: zod `.max()` on MCP schemas; `.slice(0, N)` on free text in routes; JSON body cap (256 KB in the HTTP API, checked on `content-length` and actual text length).
- Paid calls only on POST, after the admin check.
- Wrap untrusted text sent to Claude in tags and tell the model to ignore instructions inside it.
- Outbound fetches to user-supplied URLs go through an SSRF guard (http/https only, standard ports, `isPublicRoutableHost`, reject `.local/.localhost/.internal/.lan/.home/.corp`, re-check every redirect manually, size cap, timeout).
- Validate return paths (`next=`) to be same-site relative paths.

## 8. Tests

```ts
// tests/helpers/services.ts (essentials)
import Database from "better-sqlite3";
import { drizzle } from "drizzle-orm/better-sqlite3";
import { migrate } from "drizzle-orm/better-sqlite3/migrator";

export const BASE_URL = "http://localhost:5173";
export const ADMIN_EMAIL = "admin@example.com";

export function createTestServices(options: { ai?: AppAi; env?: Record<string, string> } = {}) {
  const db = drizzle(new Database(":memory:"), { schema });
  migrate(db, { migrationsFolder: "db/migrations" });             // real migrations every test
  const config = loadConfig({
    PUBLIC_BASE_URL: BASE_URL, ADMIN_EMAILS: ADMIN_EMAIL,
    BETTER_AUTH_SECRET: "test-secret-test-secret-test-secret-123",
    GOOGLE_CLIENT_ID: "test", GOOGLE_CLIENT_SECRET: "test", ...options.env,
  }, "node");
  return createServices({ config, db, media: null, fetchClientMetadata: fetchClientMetadataViaFetch, ai: options.ai });
}

export const request = (services: Services, path: string, init?: RequestInit) =>
  handleRequest(new Request(`${BASE_URL}${path}`, init), services, async () => new Response("<html>page</html>"));

/** Signed session cookie for a new user (stands in for Google sign-in). */
export async function sessionCookieFor(services: Services, email: string) {
  const { serializeSignedCookie } = await import("better-call");
  const ctx = await services.auth.$context;
  const id = crypto.randomUUID(), now = new Date();
  await services.db.insert(schema.user).values({ id, email, name: "Someone", emailVerified: true, createdAt: now, updatedAt: now });
  const session = await ctx.internalAdapter.createSession(id);
  return (await serializeSignedCookie("better-auth.session_token", session.token, ctx.secret)).split(";")[0]!;
}
```

Patterns:

- **Route tests** call `loader`/`action` directly with `{ request, params, context: createRouterContext(services) }`. A small `run()` helper catches thrown `Response`s and unwraps `data()` results (`type === "DataWithResponseInit"`, status in `init.status`).
- **FakeAi** implements the AI port, returns scripted results, and records every call in `calls`. Assert `calls.length === 0` for refused requests.
- **MCP tests** send JSON-RPC over `request(services, "/mcp", …)` with an API key or a token from `connectTool()` (full OAuth flow in-process: register → authorize → consent → token with PKCE). Parse either JSON or SSE `data:` lines.
- **Browser tests** (optional) build the Node host and point `ANTHROPIC_BASE_URL` at a local mock HTTP server that returns canned Messages API responses, so the real adapter runs without paid calls.
- **Live tests** live in `tests/live/*.live.ts`, skip when `ANTHROPIC_API_KEY` is unset, and run only through `npm run smoke:ai`.
- Cite requirement IDs in test names if your project has them.

## 10. How a new feature uses each layer

1. **Schema**: add tables in `server/db/app-schema.ts` → `npm run db:generate` → review the SQL.
2. **Core**: types, zod validation, a `XRepository` interface, and `createX()` with injected `now`/`newId`.
3. **Adapter**: `createXRepository(db)` with Drizzle; multi-statement writes through `atomic()`.
4. **Wire**: add to `Services` and `createServices`.
5. **UI**: page route with loader/action; admin writes start with `requireAdminWrite`.
6. **MCP** (if tools should use it): `registerTool` with a zod shape, call the core function, return `result(...)`. Share schemas with the HTTP API.
7. **Claude** (if AI is needed): add a method to the AI port, implement it in the adapter with a zod output schema, add it to `FakeAi`, call it from core, expose it through a POST route after the admin check. Results are suggestions; the user saves through a normal action.
8. **Tests**: core unit test, route test with `createTestServices`, MCP test if exposed, `FakeAi` for AI paths.
